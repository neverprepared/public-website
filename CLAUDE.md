# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Overview

`neverprepared/public-website` is the static marketing/blog site for
**neverprepared.com**. It is an [Astro](https://astro.build) 5 project scaffolded
from the official `blog` starter template ("Astro Starter Kit: Blog", Bear Blog
theme) and deployed to GitHub Pages.

There is no backend, no API, no MCP server, and no client-side framework
(React/Vue/Svelte are not installed). Everything is statically rendered at build
time.

## Architecture

- `astro.config.mjs` — `site: 'https://neverprepared.com'`, integrations:
  `@astrojs/mdx` and `@astrojs/sitemap`. No `output`/adapter is set, so the
  default fully static build applies.
- `src/consts.ts` — global `SITE_TITLE` / `SITE_DESCRIPTION`, imported by pages
  and the RSS feed.
- `src/content.config.ts` — one content collection, `blog`, loaded via
  `glob({ base: './src/content/blog', pattern: '**/*.{md,mdx}' })`. Frontmatter
  schema (zod): `title`, `description`, `pubDate` (coerced to Date),
  optional `updatedDate`, optional `heroImage` (an `image()` asset reference).
- `src/pages/` — file-based routing. Live routes:
  - `/` — `index.astro`, hero/landing page.
  - `/about` — `about.astro`, rendered through the `BlogPost` layout.
  - `/podcast` — `podcast.astro`, "Coming soon" placeholder.
  - `/in-the-news/` — `in-the-news/index.astro`, lists `blog` collection entries
    sorted by `pubDate` descending.
  - `/in-the-news/<slug>/` — `in-the-news/[...slug].astro`, `getStaticPaths()`
    over the `blog` collection; renders through `layouts/BlogPost.astro`.
  - `/rss.xml` — `rss.xml.js`, feed built from the `blog` collection.
  - `/sitemap-index.xml` — generated by `@astrojs/sitemap`.
- `src/layouts/BlogPost.astro` — article layout (hero image, dates, prose).
- `src/components/` — `BaseHead.astro` (all `<head>` metadata: canonical URL,
  OpenGraph, Twitter card, RSS + sitemap links, font preloads, imports
  `styles/global.css`), `Header.astro`, `Footer.astro`, `FormattedDate.astro`,
  `HeaderLink.astro`.
- `src/content/blog/` — the posts. Currently still the five starter-template
  placeholder posts (`first-post.md`, `second-post.md`, `third-post.md`,
  `markdown-style-guide.md`, `using-mdx.mdx`).
- `src/assets/` — images processed by Astro (`sharp`); `public/` — assets served
  verbatim (`favicon.*`, `fonts/`, and `CNAME` containing `neverprepared.com`).

## Key commands

| Command | Action |
| :-- | :-- |
| `npm install` (`npm ci` in CI) | Install dependencies |
| `npm run dev` | Dev server at `localhost:4321` |
| `npm run build` | Static build to `./dist/` |
| `npm run preview` | Serve the built site locally |
| `npm run astro -- <cmd>` | Astro CLI (`add`, `check`, …) |

**There is no test suite and no lint script.** `package.json` defines only
`dev`, `build`, `preview`, and `astro`; there are no test/lint dependencies.
`npm run build` (which type-checks `.astro` templates) is the only automated
verification available — run it before opening a PR. `npm run astro -- check`
requires installing `@astrojs/check` + `typescript` first; neither is a
dependency today.

## CI/CD

`.github/workflows/deploy.yml` — on push to `main` (or `workflow_dispatch`):
Node 22 → `npm ci` → `npm run build` → upload `./dist` as a Pages artifact →
deploy to the `github-pages` environment. There is **no CI on pull requests**;
nothing validates a branch before merge.

## Conventions

- TypeScript config extends `astro/tsconfigs/strict` with `strictNullChecks`.
- Indentation is tabs; single quotes in `.ts`/`.astro` frontmatter.
- Component `Props` are typed via an `interface Props` or
  `type Props = CollectionEntry<'blog'>['data']`.
- Page-scoped styles live in `<style>` blocks inside the `.astro` file; shared
  tokens and resets live in `src/styles/global.css`.
- Global text (site title/description) comes from `src/consts.ts` — do not
  hardcode it in pages.
- New posts are Markdown/MDX files in `src/content/blog/` and must satisfy the
  collection schema; they appear automatically under `/in-the-news/`.
- `CLAUDE.md` is ignored by a global gitignore — commit it with `git add -f`.

## Known gaps (do not assume these work)

- **The Pages deploy workflow is currently broken on `main`.** `package.json`
  lists `@img/sharp-darwin-arm64` as a *direct* dependency. It is a
  macOS-only optional binary of `sharp`, so `npm ci` fails on the workflow's
  `ubuntu-latest` runner with `EBADPLATFORM ... wanted {"os":"darwin"}`. Every
  `Deploy to GitHub Pages` run since 2026-02-11 fails at the install step in
  ~12s. Removing that dependency (plain `sharp` already pulls the right
  platform binary) makes `npm ci` + `npm run build` succeed on Linux —
  verified locally. Not fixed here; this repo's own build is otherwise green.

- **Dead `/blog` links.** No `/blog` route exists — posts live under
  `/in-the-news/`. But `src/pages/rss.xml.js` emits `link: /blog/${post.id}/`
  and `src/pages/about.astro` links to `/blog`. Both 404.
- **Nav is commented out.** `src/components/Header.astro` only links `/`; the
  `In The News`, `Podcast`, and `About` links are commented out, as is the CTA
  button on the home page. Those pages build and are reachable by URL but are
  not linked from anywhere.
- **README is the unmodified starter-template README** and describes the generic
  Astro blog template, not this site.
- Blog content is still placeholder starter posts.
